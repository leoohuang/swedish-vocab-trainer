# ord. 历史试部署记录

2026-10-25：当前先在本地开发和使用，入口为 http://127.0.0.1:5173/。正式上线目标是独立域名和托管服务上的网站，不依赖 ChatGPT 登录。下面的 Sites 配置仅保留为历史试部署记录，不是正式部署方案。

站点地址：https://ord-swedish-practice.tianleleo.chatgpt.site

首次发布按 Sites 默认方式限制为仅所有者可访问，需要使用对应账号登录。GitHub 源码仓库仍为私有。若之后开放给其他用户，需要另行配置网站访问范围及 API 用量控制。

## 运行方式

- React 页面与静态资源构建后嵌入一个 Worker ESM 入口，浏览器上传与解析文件的方式保持不变。
- 云端 API 复用本机已经测试的词汇提取逻辑，使用 Web Request/Response 和服务端运行时环境变量。
- `OPENAI_API_KEY`、`OPENAI_MODEL`、`OPENAI_BASE_URL`、`AI_API_STYLE` 通过 Sites 运行时密钥配置，不放在 Git、部署清单或浏览器代码里。
- `npm run build` 同时生成前端与 `dist/server/index.js`；`npm run build:client` 仅构建前端。本机 `npm run dev` 和 `npm start` 继续使用 Node 接口。
- `.openai/hosting.json` 记录 Site 身份，保留其中的 project_id，后续更新复用同一站点。

## 本机词库如何带到线上

词库、分组进度、声音设置仍保存在访问该地址的浏览器里，没有账号数据库同步。本机地址与线上地址的数据相互独立。

1. 在本机页面进入「数据与设置」，导出完整 JSON 备份。
2. 在目标页面进入「数据与设置 → 合并导入备份」，导入该 JSON，保留目标页面已有的词库与进度。
3. 核对词库、分组和进度后再继续学习。

JSON 导入默认只在浏览器内完成，不会因为使用线上页面就上传个人词库。只有用户授权的 AI 整理文字才发送至配置的模型服务。换设备或浏览器也需要自行导出、恢复。
