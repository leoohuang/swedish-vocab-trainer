# 第一版验证记录

日期：2026-10-17。环境：macOS、Node.js 26.10.0、Chrome，由 Playwright 启动独立测试会话。测试只使用合成词条和合成文件，没有读取个人词库。

## 已通过

- `npm run build`：TypeScript 检查和 Vite 生产构建通过。
- `npm test`：11 项核心测试通过。涵盖混乱分隔符、跨行释义、原文来源、表头映射、缺失字段、Unicode 与瑞典语变音符号、回练上限、提示计分、重复提交、复习历史幂等和备份校验。
- `npm run test:e2e`：11 项 Chrome 浏览器测试通过。涵盖导入确认、待整理修正、刷新保留、编辑弹窗、选择到拼写、错误与提示计分、暂停续练、错词回练、完成记录、JSON 下载恢复、错误文件、损坏备份、重复词合并备注，以及真实 DOCX / XLSX / CSV / PDF 文件导入。
- 首页在 1440、1024、768、390、320 px 宽度检查无页面横向溢出，320 px 整理弹窗可用；已目视检查桌面首页、手机首页和 390 px 练习页。
- 本机开发服务返回 HTTP 200；预览地址为 `http://127.0.0.1:5173/`。
- Git 忽略规则已核对：依赖、构建结果和测试运行文件不会进入源码同步。

## 尚未验证或实现

- 未使用真实用户文件测量识别准确率，不能据合成样本承诺任意笔记均可正确整理。
- 尚未实测 Safari、Firefox 和实体手机；没有验证设备上的瑞典语朗读可用性。
- 未接入 AI、OCR、账号与跨设备同步，未部署线上服务或推送 GitHub。
- `npm audit` 目前报告 Mammoth → argparse → sprintf-js 链上的 3 项中等风险条目，涉及 sprintf-js 格式化精度导致的拒绝服务。当前应用调用的是浏览器文档提取入口，没有调用 argparse 的命令行路径。没有用降级到古老 Mammoth 版本的方式消除报告；正式发布前需复查上游修复和依赖可达性。

浏览器截图和测试下载文件位于被 Git 忽略的 `test-results/`，可以重新运行测试生成。

## API 已配置后的模型权限修复（2026-10-17）

- 服务已读到密钥；真实失败原因为 OpenAI 对配置模型 `gpt-5-mini` 返回 HTTP 404 / `model_not_found`，响应要求组织认证。模型出现在列表中不能证明有调用权限。
- 同一配置下，`gpt-4.1-mini` 对两条合成词汇的真实结构化请求成功；已将本机模型配置及项目默认模型切换到此模型，密钥没有改动或提交。
- 独立 Chrome 测试使用一段合成瑞典语短文，真实调用本机接口与上游模型，成功进入确认页，返回 5 个候选词。没有发送用户文件。这验证可用性，不代表挑词质量已充分验证。
- 错误提示现区分组织认证、模型权限、API 密钥失效、额度不足、限流和接口路径错误；不把上游原始错误转发给浏览器，避免其中的凭据回显。
- 导入窗口在重新获得焦点时和可见时每 10 秒自动检查本机配置状态，无须丢弃材料重开窗口。
- 核心和服务测试 28 项通过，AI 浏览器测试 5 项通过，生产构建通过。

## v0.3：固定分组与练习反馈（2026-10-17）

- 每个词库按导入顺序固定分组，每组 10 词。组号写入本机词条及完整备份；旧版词库自动补组号，保留原有练习次数、复习时间和当前场次。
- 默认选择第一个未完成的组；部分已练组默认只选剩余新词，全部练过后不自动回到第一组。已学组仍可手动重练，到期复习使用独立入口。删除和追加词不重排已有组号，新词不重新打开已学过的末组。
- 使用浏览器 Web Audio 在本机合成打字声、正确音和错误音，无需下载音效；答对调用设备的瑞典语语音。开始练习和用户交互时解锁音频，切题或退出取消旧朗读，恢复已有反馈不会重复播报。
- 自动朗读、键盘音效、答题音效可分别关闭，并随本机数据和 JSON 备份保存。错误轻震、正确轻微回弹；尊重系统减少动态效果设置。
- Chrome 当前可找到瑞典语 Alva（sv-SE）语音。测试核对了语音调度及音频节点与波形参数，未声称所有设备的扬声器、语音包或系统静音状态均已验证。
- 核心测试 35 项通过，包括 7 项分组、旧数据兼容、稳定组号与声音设置备份测试。
- 原有及新增 20 项浏览器场景通过，另新增并通过“实际完成第一组 10 词的 30 道选择与拼写题后，刷新默认第二组”场景，共 21 个浏览器场景。新增分组与声音相关场景共 5 项。
- 浏览器测试保留真实 Web Audio 节点但静音输出，并截获朗读，避免自动测试反复打扰用户；核对新答案触发、错误不朗读、正确音与错误音分离、关闭后不触发，以及设置持久化。
- 320 px 分组弹窗无横向溢出，已目视检查布局；系统减少动态效果时答题卡动画为 none。生产构建通过。
