# ord. 第一版试用说明

## 先体验练习

1. 在首页点击「生活里的瑞典语」示例词库。
2. 点击「开始一组练习」，词库已固定分成每组 10 词，默认选中第一个未完成的组。50 个词就是 5 组，尾组不足 10 个也能直接练。无需逐词勾选。
3. 先看一遍单词，再开始词义选择。
4. 进入拼写后，根据释义输入瑞典语；en / ett 在提示里给出，答案只输入词本身。
5. å、ä、ö 可以直接点屏幕按钮输入，不能用 a、o 代替。
6. 每个词两次独立拼写正确达到本轮目标；用过提示的题会再次出现。每词最多尝试四次，避免卡住。
7. 「保存并退出」可暂停，刷新页面后在首页继续。完成一组后，下次默认接着下一组；已学过的组可手动选择重练。

词义题可按数字 1–4 选择；检查答案后按 Enter 继续。

答对时自动播放瑞典语读音；输入时有轻柔键盘声，正确与错误各有不同音效和动画。在练习右上角的「声音」菜单或「数据与设置 → 练习声音」中，可以分别关闭自动朗读、键盘声和答题音效，设置会随进度保存。

分组内若已有部分词练过，默认只练剩余新词；全部学过后不自动重复第一组。到期复习使用独立入口。「自己选词」仍可用于临时挑选最多 20 个词。新增词不会改动已有组号，也不会重新打开已练过的末组。

## 再试自己的笔记

1. 点击「导入我的单词」，上传 TXT、MD、CSV、XLSX、DOCX 或文字型 PDF；也可以粘贴内容。
2. 整理页显示词条、释义、词形和原文，可以逐条修改。
3. 检查后勾选准备学习的词，点击「保存词库」。
4. 没有勾选或缺少信息的条目保留在「待整理」，之后可以继续补充。

现在默认提供 AI 整理入口：单词合集完整整理，课文按水平和目标词数推荐词汇，混合笔记分类整理。先按 [AI 整理接入](AI整理接入.md) 配置服务，再勾选发送授权并运行。AI 释义、原句和推荐原因均可核对；不确定条目保留待整理。

没有 API 密钥时，可切换到「本机规则整理」继续体验，适合明确分隔的单词表，不用于课文理解。

## 保存你的内容

数据保存在当前电脑、当前浏览器、当前访问地址下。`localhost`、`127.0.0.1` 和不同端口属于不同存储地址，建议始终使用同一链接。

进入「数据与设置」导出完整 JSON，可在以后恢复词库、待整理内容和进度。CSV 仅保存词条，不能恢复学习进度。恢复 JSON 会要求确认后替换当前记录。

没有云同步，清理网站数据或更换浏览器前需要备份。开发目录和 GitHub 源码不包含浏览器里保存的个人词库。

## 建议这次重点试什么

- 用一小段真实笔记，看配对是否准确，待整理是否好找。
- 完整练一组，感受选择题与拼写之间的节奏。
- 故意输错或用提示，查看回练是否自然。
- 暂停、刷新再继续，检查进度是否保留。
- 告诉我们最不顺手的步骤，下一轮优先调整。

## 按单元或分类命名

导入窗口顶部可以先填写「词库名称」，例如「第 1 单元」「饮食与餐厅」。手动填写后，上传文件不会用文件名覆盖；没有手动修改时，会自动建议文件名。确认整理结果时仍可修改名称。

修改已有词库：在「我的词库」打开对应词库，点击「重命名」，输入新名称并保存。名称会同步显示在词库卡片、标题和分组中；单词、收藏、分组、练习记录和暂停场次均保留。
