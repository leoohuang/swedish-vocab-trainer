# AI 材料整理

> 当前公开网站默认使用访客自带 API（public-byok），无需网站密码，也不回退到站长密钥。见 [公开网站与自带 API](public-byok.md)。以下服务端密钥/密码说明用于本机或显式设置 `SITE_ACCESS_MODE=private` 的私有部署。

当前版本将文件读取与词汇理解分开。用户不需要先把学习材料整理成固定模板。

## 使用方式

1. 点击「导入我的单词」，默认使用 AI 理解材料。
2. 上传或粘贴单词合集、课文或混合笔记。
3. 材料类型可以自动判断，也可自行指定。课文可选择学习水平和推荐词数，词汇合集和混合笔记保留明确词条，不按目标词数删减。
4. 明确同意发送文字后，点击「用 AI 整理」。
5. 检查候选词、释义、词形、原文、原句和推荐原因。AI 补充的释义单独标记，无法匹配来源或模型标记不确定的词不会默认勾选。
6. 课文中超出目标数量的候选词仍保留，可以手动补选；完整确认后进入现有练习。

当前支持 TXT、MD、CSV、XLSX、DOCX、文字型 PDF。内容可自由组织；图片、扫描件和旧版 DOC 暂不支持。每份文件最大 10 MB、PDF 最多 80 页，单次 AI 材料最多 30000 字符、500 个词汇候选。超限需要分批，系统不截取前半份冒充完整整理。

## 服务端配置

将项目根目录 `.env.example` 复制为 `.env.local`，填写：

```dotenv
OPENAI_API_KEY=填写自己的API密钥
OPENAI_MODEL=gpt-4.1-mini
OPENAI_BASE_URL=https://api.openai.com/v1
AI_API_STYLE=responses
```

不要把密钥放入 `VITE_` 变量或浏览器代码，也不要提交 `.env.local`。页面不提供密钥输入框。保存配置后，在整理窗口点击「刷新状态」。配置按请求读取，无须重启服务。

默认使用 OpenAI Responses API 及 JSON Schema 结构化输出，`store: false`。模型名可修改为账户中可用且支持结构化输出的模型。其他兼容服务可以更换 `OPENAI_BASE_URL`，并在需要时把 `AI_API_STYLE` 改为 `chat`，使用 Chat Completions JSON Schema；并非所有标称兼容的服务都支持严格 JSON Schema，需对实际服务验证。

文档依据：[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)、[GPT-4.1 Mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini)。这些说明不能证明当前账户有模型访问权限。

运行：

```sh
npm install
npm run dev
```

本机地址为终端打印的地址。若需要预览构建结果，可用 `npm run build` 后 `npm run preview`，仍包含本机 AI 接口。也可 `npm run build` 后 `npm start`，通过本机 Node 服务同时提供构建页面和 AI 接口。直接用纯静态服务器打开 dist 不提供 AI 接口。

## 数据与校验

- 文件在浏览器本机读取，授权后发送本次文字块；不上传文件原件，不发送学习次数、错误记录或账号信息。
- 「课文跳过已练过的词」默认关闭；主动启用时额外发送最多 2000 个已练词条，不包含练习记录。
- 服务端保存密钥，页面只能查询是否配置、模型名称、服务主机名和接口类型。
- 一次材料按来源块顺序分批处理，最多八个模型请求。每批有 120 秒超时和 16000 输出 token 上限，不做自动重试。失败会保留用户材料，不静默切换成本机规则。
- 点击取消会中断浏览器请求，并向上游传递取消信号；已经发生的模型计算可能仍产生费用。
- 模型返回通过结构和来源匹配校验。不存在的来源编号导致整次失败；无法逐字匹配的引文不默认选中。未匹配原文的例句不以原句展示。声称来自原文但没有逐字释义依据时，改标 AI 补充。
- 词义、词性、原形和重要性仍可能判断错误。来源匹配只能证明引用文字存在，不能证明语义判断正确，导入需要用户核对。
- AI 元信息随词条、待整理记录和 JSON 完整备份保存，旧版本机词库无须迁移。CSV 仍只包含基本词条和备注。

## 本机服务边界

该接口为当前电脑试用准备，只允许 loopback 主机和同源浏览器请求。请求体限制 256 KB，最多两个并发任务、每分钟十次整理。没有公开服务所需的登录、用户限额或计费控制，不应把此版本直接暴露到公网。

## 目前验证状态

接口、参数、来源检查、数据保存和浏览器交互有合成数据及模拟模型响应测试。现已使用配置的 API 服务完成小型合成材料的真实调用测试，默认模型改为已验证可调用的 `gpt-4.1-mini`。这只验证本机当前账户与样本的调用路径，不保证其他账户权限，也不代表复杂文件整理质量已达标。真实学习材料仍需核对遗漏、释义、词形和推荐难度。

如果密钥已配置但模型返回组织认证要求，需要在 OpenAI 控制台完成认证或选择账户可用的其他模型。服务端会区分组织认证、模型权限、密钥失效、额度不足和接口路径错误；不把模型可见于列表等同于已经可以调用。
